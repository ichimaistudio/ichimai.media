# ichimai.media

ICHIMAI.（@ichimai.studio）の Instagram 投稿素材の置き場（GitHub Pages で公開）。

- `rNN/` … 各投稿の素材（reel.mp4 / cover.jpg / story.jpg / carousel 画像）
- `tools/render.py` … HTML（window.render(t)）を Playwright でフレーム画像・静止画にする
- `tools/music.py` … 著作権フリーの簡単な BGM（自作合成）を生成する
- `templates/` … これまでの動画・画像のHTMLテンプレート

公開URL: https://ichimaistudio.github.io/ichimai.media/
